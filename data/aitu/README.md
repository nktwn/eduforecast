# data/aitu — финансовый профиль Astana IT University

**Файл:** `financials_2019_2020.csv`. Источник — финансовая отчётность ТОО «Astana IT University» за 2020 год, значения в тыс. тенге. Колонки:

| колонка | смысл |
|---|---|
| `year` | год: 2020 — отчётный, 2019 — сравнительные данные («на начало периода» в балансе) |
| `indicator` | код показателя (используется в `src/finance/aitu_profile.py`) |
| `label` | название показателя по отчётности |
| `value` | значение |
| `unit` | `тыс. тенге`, для численности — `человек` |
| `page` | страница PDF; сейчас везде **«уточнить»** — номера страниц при передаче цифр не указаны |
| `source_section` | раздел отчётности: прим. 16 (доходы), прим. 17 (расходы), баланс |
| `verified` | `false` везде: цифры прочитаны с отсканированного PDF и не сверены с оригиналом |

## Оговорки

- **Это только два года, и 2020-й — второй год работы вуза.** Тренды по ним оценивать нельзя. Описывать можно только структуру.
- **Расходы 2020 года нетипичны.** В них одной статьёй вошло возмещение коммунальных услуг и налога на имущество сразу за 2019 и 2020 годы (397 400 тыс. тенге).
- **Убыток за период** (−58 101) учитывает дисконтирование беспроцентной финансовой помощи. **Убыток от деятельности** (−601 744) равен «доходы минус расходы».
- **Разбивка доходов от услуг** (госзаказ, платное обучение, научный проект, курсы) и **численность работников** даны только за 2020 год.
- **Годы 2021–2025 сюда пока не внесены.** Их добавят вручную по той же схеме колонок.

## Проверки

Проверки сумм делает `python -m src.finance.aitu_profile`, тот же код вызывают тесты. Допуск 1 тыс. тенге, более крупные расхождения выводятся отдельным списком.
- доходы по источникам = итог доходов;
- доходы от услуг по подпунктам = доходы от услуг;
- расходы по статьям = итог расходов;
- активы = обязательства + капитал;
- доходы − расходы = убыток от деятельности;
- дополнительно: изменение капитала за 2020 год = убыток за период.

Состояние на 2026-10-16:
- расхождение есть только в одном месте: доходы 2020 по источникам дают 1 281 265 против итога 1 281 266, то есть на 1 тыс. тенге. Скорее всего, это округление в отчёте; укладывается в допуск;
- расхождений больше 1 тыс. тенге нет.
