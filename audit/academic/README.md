# Аудит Academic: скрипты пересчёта

Скрипты пересчитывают числа из `ACADEMIC_AUDIT.md` и статьи. Результаты (маленькие CSV) лежат в `results/academic_audit/` и закоммичены. Предсказания по регистрациям пишутся в `results/academic_audit/predictions/`, эта папка в `.gitignore`.

**Происхождение кода.** Исходные скрипты аудита от 2026-10-09 хранились во временной папке сессии и не сохранились. Эти скрипты восстановлены 2026-10-16 по описанию методики в `ACADEMIC_AUDIT.md` (§1–§4) и коду ноутбуков `02–05`.
- Признаки, LR, RF, численности выборок и оценка опубликованных чекпойнтов детерминированы. Они воспроизводят числа аудита точно.
- Переобучение сетей (LSTM полный, LSTM с обрезкой, TFT-inspired) идёт по тому же описанию, но поток случайных чисел другой: порядок батчей, обрезка и разбиение на валидацию. Поэтому средние по сидам отличаются от статьи на 0.001–0.02. Сравнение с числами статьи: `results/academic_audit/paper_vs_recomputed.md`.

## Что нужно

- `data/raw/*.csv` (OULAD) и `data/processed/*.csv` из `notebooks/02_features`. Разбиение train/test берётся из `data/processed/{train,test}_static.csv`.
- `results/lstm_best_model.pth`, `results/tft_best_model.pth` — опубликованные чекпойнты, нужны только для `step2 checkpoints`.
- Окружение `.venv`: torch 2.12, scikit-learn 1.8, shap 0.51, pandas 3.0, numpy 2.4. Сеть не нужна.

## Как запустить

Из папки `audit/academic`:

```bash
P=../../.venv/bin/python
$P step1_static.py                  # ~30 с: проверка пересборки признаков, LR/RF с обрезкой, численности
$P step2_nets.py checkpoints        # ~15 с: опубликованные чекпойнты, без обучения
$P step2_nets.py train              # обучение сетей, CPU, сиды 42/43/44 (время ниже)
$P step2_nets.py rescore            # пересчёт AUC сетей по сохранённым предсказаниям, ~10 с
$P step3_bootstrap.py               # ~2 мин: bootstrap по студентам, 2000 ресэмплов
$P compare_paper.py                 # ~1 с: таблица «статья / пересчитано / совпало»
$P risk_model_eval.py               # ~30 с: модель риска страницы «Студенты» до/после, калибровка
```

**Время обучения сетей** (Apple M2, 8 ядер, CPU, по 2 потока torch на процесс):
- одна модель на один сид — 3.5–9 мин; все 9 моделей последовательно — около 48 мин;
- три процесса параллельно — около 18 мин:

```bash
for m in lstm_full lstm_trunc tft; do $P step2_nets.py train --models $m --threads 2 & done; wait
```

## Сиды и соглашения

- **Сиды:** LR/RF `random_state=42`; сети 42, 43, 44 (`random`, `numpy`, `torch`, отдельный `torch.Generator` для батчей и обрезки); bootstrap `numpy.random.default_rng(42)`; валидация сетей — 10% студентов train, `train_test_split(random_state=42)` со стратификацией по студенту.
- **Неделя k** — данные недель 0…k, то есть дни ≤ 7k. Сети читают выход на шаге k.
- **«Ещё учащиеся» на неделе k** — регистрации без `date_unregistration ≤ 7k`.
- **Среднее ± std по сидам** — выборочное стандартное отклонение (ddof = 1).

## Файлы результатов

| файл | содержание |
|---|---|
| `populations.csv` | размеры теста и train, отчисленные к неделе k, ещё учащиеся |
| `static_auc.csv` | AUC LR/RF: весь курс и обрезка k = 5/10/20/39, все и ещё учащиеся |
| `nets_checkpoints_auc.csv` | опубликованные чекпойнты: способ ноутбуков и «недели ≤ k, шаг k» |
| `nets_auc_{lstm_full,lstm_trunc,tft}.csv` | переобученные сети: AUC по сидам, эпоха, время |
| `bootstrap.csv` | TFT-inspired (сид 42) минус каждый baseline, 95% ДИ по студентам |
| `paper_vs_recomputed.{csv,md}` | сравнение с числами статьи до 3 знаков |
| `risk_model_eval.csv` | модель риска в приложении: прежняя (весь курс, оценка на обучающих данных) и новая (недели ≤ k, вне обучающей выборки), по факультетам и в целом |
| `risk_model_reliability_k5.csv` | график надёжности на k = 5: без калибровки, Платт, изотоническая |
