## 7. Конформные интервалы и SHAP

**Интервалы.** Нормированные сплит-конформные интервалы 80%:
- невязка делится на волатильность вуза — sd его роста по годам до точки прогноза, минимум 3 значения, снизу ограничена 5-м процентилем;
- калибровка — на всех более ранних прогнозах.

Покрытие выше номинала: 84–91% против 80%. Интервалы консервативны, то есть шире, чем нужно. Ниже 80% оказалась одна ячейка: цитирования крупных вузов, 79.8%. Терцили размера — по медиане works_count за 2010–2025.

**SHAP.** TreeSHAP для LightGBM; для Ridge — модуль стандартизованного коэффициента. Модели переобучены на всех данных до 2025 (`shap_importance.csv`).
- Во всех целях первым или вторым идёт прошлый уровень (level_lag1): чем больше вуз, тем медленнее рост, то есть регрессия к среднему.
- Затем идёт прошлый рост (g_lag1).
- Для unique_authors первый признак — log числа работ.
- Для международных счётчиков в первую четвёрку входит рост авторов или работ.
- Признаки страны в первую четвёрку не входят ни для одной цели.

SHAP описывает модель, а не причины роста вузов.

## 10. Решения, принятые мной

1. **D1. Возраст.** Признак модели «age» — как в этапе 2. Возрастная группа для базовой модели age_mean — по AGE_RULE.
2. **D2. top10_share** оценивается только по целевым годам ≤ 2023 (правило этапа 2 для показателей качества).
3. **D3. Прогнозы долей** ограничены отрезком [0, 1].
4. **D4. Тип организации.** Только тип OpenAlex «education». Запросы расширены на все типы, чтобы остальные попали в таблицу с причиной отказа.
5. **D5. ROR parent.** Кандидат, у которого в ROR указана родительская организация, — подразделение другой организации, исключается.
6. **D6. Ручная проверка статуса вуза** — для кандидатов без «university/academy/college/polytechnic/school» в названии. Skoltech и UNIST выдают собственные дипломы и остаются. CEITEC — исследовательский центр консорциума университетов Брно, исключён. Правило «тип не education» само по себе CEITEC не исключает: OpenAlex и ROR относят его к education.
7. **Поправка 1 (до моделей):** naive исправлен на naive этапа 2, мощность для новых целей пересчитана.
8. **Мировая случайная выборка не нужна:** после правила ряда отобрано 50 вузов (≥ 40).
9. **Год основания по ROR** у переименованных или разделённых вузов — это год новой организации: Воронежский ГТУ (2016), Эскишехир и Конья (2018), Западнопоморский (2009).
10. **AITU и MBZUAI** не проходят правило ряда: внешние единицы, в обучение не входят.
11. **Целостность загрузки.** Записи атомарные. Перед сборкой — проверка кэша. Работы вуза используются, только если по каждому году их столько, сколько сообщает OpenAlex.
12. **Волатильность для конформных интервалов** — sd всего ряда роста вуза до точки прогноза, как в предрегистрации. Первая версия кода брала только годы, где есть все лаговые признаки. Исправлено до записи результатов в отчёт; C1 и C2 это не затрагивает. Если значений меньше 3, берётся медиана панели (в оценке таких случаев 0). Для AITU волатильность снизу ограничена 5-м процентилем панели.
13. **Процентиль AITU** — доля вузов панели с меньшим значением, половина равных учитывается как меньшие. Год 2025, сравнение с 50 вузами основной панели.
14. **«Исходные 13»** — 13 вузов этапа 2 без SDU, включая AITU и MBZUAI, по новой выгрузке. На этих 13 AITU и MBZUAI участвуют в оценке, как в этапе 2.
15. **Статусы в реестре фактов.** «проверено» — только решения C1/C2, выигрыши основной модели и покрытие на расширенной панели (зафиксированы заранее и воспроизведены). «исследовательское» — сравнение на 13 вузах, неосновные модели, прогноз и процентили AITU.
16. **Страница Research.** Блок этапа 3 читает реестр фактов, который лежит в git, поэтому работает в свежем клоне без данных. Иллюстрация Prophet оставлена ниже, с пометкой, что её ряд — другая выгрузка.

## 11. Неудачи

1. **C2 не пройден ни для одной цели** — ни на 50, ни на 13 вузах. Против среднего роста панели выигрыш 1–17% (≥ 10% только у цитирований), против возрастной группы — 1–10%, ниже порога везде. Подробно — раздел 6.3.
2. **C1 не пройден для долей** (intl_collab_share, top10_share) на обеих панелях. На 13 вузах модель для долей хуже naive (−2…−6%).
3. **C1 для n_intl_works не пройден на 13 вузах** (CI до +0.009). На 50 вузах пройден.
4. **Smoke-тест и итог расходятся** для works_count на 13 вузах (LOUO: не пройден → пройден) из-за изменения данных OpenAlex за 10 дней. Результат на 13 вузах пограничный.
5. **Правило «тип не education» не исключило CEITEC**: OpenAlex и ROR относят его к education. Понадобились правила D5 (ROR parent) и D6 (ручная проверка), записанные до запуска.
6. **Интервал AITU для цитирований неинформативен** (590–10 472) из-за взрывного старта AITU. Метод не подгонялся.
7. **Дубли аффилиаций по пересечению работ не доказуемы.** 27 пар с общими работами > 10% — соавторство. Независимость вузов для бутстрепа не выполняется, интервалы могут быть оптимистичны.
8. **Первая версия Research-блока не открывалась** в настоящем запуске Streamlit (не находился модуль `src`), хотя тесты проходили. Найдено по скриншоту, исправлено.
