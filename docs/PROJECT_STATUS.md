# Состояние проекта EduForecast-SIS

Дата: 2026-10-09. Ветка `main`, последний коммит `3867cf3`.
Отчёт составлен по коду, сохранённым данным и результатам **без новых сетевых запросов и без переобучения моделей**.

**Обозначения:**
- `файл:строка` — строка в файле;
- `ноутбук, cell N` — ячейка Jupyter-ноутбука;
- «аудит-скрипты сессии» — скрипты и CSV аудита Academic от 2026-10-09 во временной папке сессии Claude (`…/scratchpad/academic/`), **не в репозитории** (см. §7);
- «не проверено» — утверждение не удалось сверить с артефактом.

Термины:
- **AUC** — площадь под ROC-кривой: 0.5 — случайное угадывание, 1.0 — идеальное разделение;
- **MAE** — средняя абсолютная ошибка;
- **naive** — прогноз «как в прошлом году»;
- **утечка (leakage)** — модель видит информацию, недоступную на момент решения;
- **SHAP** — разложение прогноза на вклады признаков;
- **bootstrap-ДИ** — доверительный интервал, полученный повторными случайными выборками.

Старый файл `PROJECT_STATUS.md` в корне (от 2026-10-01) устарел, см. §3.
