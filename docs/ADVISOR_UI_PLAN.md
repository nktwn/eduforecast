## 2. Дублирование кода

- **Шапка и сайдбар** собираются вручную на каждой странице. Есть три варианта: `sidebar_logo`, `sidebar_brand` и свой блок в `05_Finance.py`; везде повторяются `st.set_page_config` и `st.markdown(GLASS_CSS)`.
- **Карточки KPI.** HTML-строки `metric-card` копируются в `home.py`, `01_Students.py`, `05_Finance.py`, `04_Research.py`, у каждой свои инлайн-стили.
- **Подписи признаков модели риска** по-разному названы в `risk_model.FEATURE_LABELS`, `charts.shap_bar_chart` (уже из `FEATURE_LABELS`), `02_Analytics.py` и `03_AI_Advisor.py`.
- **Цвета** захардкожены в десятках мест: `#2563eb`, `#dc2626`, `#0f172a` и др. Единого модуля темы нет, шаблона Plotly тоже: каждый график вызывает `_base()` из `charts.py`, но цвета задаёт сам.
- **Формат чисел** везде через f-строки с запятыми как разделителем тысяч (`1,234`), что для русского текста неверно.

## 3. Медленные места

1. **Модель риска.** `components/data_loader._pooled_risk(k)` (cache_resource) обучает 5 лесов вне обучающей выборки, затем `train_risk_model(module, k)` считает SHAP для факультета. Первая загрузка Студентов, Главной, Аналитики или Советника стоит 5–25 с. → Готовить заранее скриптом `scripts/prepare_app.py` в `data/app_cache/` (не в git) и читать при старте; без кэша — прежний расчёт.
2. **Prophet** в Research при первом открытии (~2–5 с, cmdstan). → Тот же скрипт.
3. **Finance:** `FinanceRepository` строит признаки для всей панели (~5 с) — приемлемо при `cache_resource`.
4. **World Bank API** — сетевой запрос с таймаутом 8 с при первом открытии Аналитики. Если сети нет, страница ждёт таймаут.
5. **`load_raw_data`:** OULAD `studentVle.csv` (10 млн строк, ~450 МБ) читается целиком при первом открытии любой Academic-страницы (~6–10 с). → Кэш в parquet тем же скриптом.

## 4. Устаревшие и спорные подписи

- **README**, раздел «Ограничения → Academic»: «Модель риска обучается на признаках за весь курс». Устарело после коммита `7af6091` (признаки по неделям ≤ k).
- **`styles.py` (сайдбар Academic) и шапка советника:** модель LLM захардкожена («GPT-OSS 120B (Groq)»). Сама смена модели не закоммичена (README, `styles.py`, `03_AI_Advisor.py`). → Этап 2: переменная окружения `ADVISOR_MODEL`.
- **Советник:**
  - система подставляет в промпт агрегаты как текст, и LLM может выдать любое число;
  - быстрые вопросы («Что делать со студентами высокого риска?», «Сравни факультет с нормой») провоцируют рекомендации без оснований;
  - нет журнала и нет проверки ответа.
- **Аналитика:** «Цель AIU 80%» и другие бенчмарки — ручные значения. Подпись «иллюстративные» есть, но советник и KPI могут принять их за факты. → В реестре они получают статус «демо».
- **Название приложения** «EduForecast-SIS | AIU» во вкладке браузера.
- **Модули «Воспитательный» и «Международный»** нигде не упомянуты. → Страницы «Концепция» с перечнем нужных данных.
